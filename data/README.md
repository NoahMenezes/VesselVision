# data/

## Source

Extension of the Z-Alizadeh Sani dataset (303 patients, 59 columns).

- UCI ML Repository, ID 411: <https://archive.ics.uci.edu/dataset/411/extention%2Bof%2Bz%2Balizadeh%2Bsani%2Bdataset>
- DOI: 10.24432/C5461K — License: **CC BY 4.0** (share/adapt with credit).
- Also mirrored at Mendeley Data DOI 10.17632/bgf5czvpg2.1.
- Citation: Alizadehsani, R., Roshanzamir, M., & Sani, Z. (2013).
  extention of Z-Alizadeh sani dataset [Dataset]. UCI Machine Learning Repository.

`fetch_ucirepo(id=411)` does NOT work (xlsx-only, not importable via the
`ucimlrepo` package), so the raw file is vendored here instead.

## Layout

- `raw/extention of Z-Alizadeh sani dataset.xlsx` — original file, unmodified.
- `raw/zani411.zip` — original download archive (provenance).
- `processed/clean.csv` — regenerated by `app.data.clean()` (deterministic).
- `feature_schema.json` — every feature: type, label, unit, group, normal range.

## Targets

- `Cath` (CAD/Normal) is the angiography result = overall CAD label
  (`CAD = (Cath == CAD)`, 216 CAD / 87 Normal).
- `LAD` / `LCX` / `RCA`: Normal/Stenotic per-artery labels.
- Leakage rule: LAD, LCX, RCA, Cath are never input features for any target.
